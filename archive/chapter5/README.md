# Archived Chapter 5 Material

This directory preserves material that is not part of the active Chapter 5 manuscript. Nothing here should be used as a scientific source for the thesis unless its historical development is being examined explicitly.

## `obsolete_project/`

- `Qwen_work/` is the complete superseded manuscript project titled *From Target Fusion to Target Reasoning*. It contains the old target-centric chain-of-thought framing, planned experiments, placeholder tables, prompt descriptions, template files, and its local bibliography.
- `Qwen_work_on_going_manuscript.pdf` is the corresponding historical rendered manuscript.

This project was archived because its central target-centric reasoning hypothesis and planned experiment structure were replaced by the completed two-stage interaction-prediction study.

## `obsolete_thesis_material/`

- `05_target_reasoning.tex` is the former thesis Chapter 5 scaffold.
- `Abstract.tex`, `01_introduction.tex`, `Publications.tex`, and `06_discussion_conclusion.tex` are snapshots taken before obsolete target-centric wording was replaced in the active thesis files.

These snapshots preserve the exact prior thesis framing for comparison.

The active manuscript's class, bibliography style, documentation, history, local bibliography, and README remain beside the authoritative source because they support independent manuscript compilation.
